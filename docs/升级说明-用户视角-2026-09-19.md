## 二、变严了的地方（安全收敛，可能"以前能做的现在不行了"）

这些是**有意为之**的收紧，不是 bug：

1. **未登录/会话失效不能再调接口**
   此前约 162 个接口不校验登录态。现在默认要求有效会话，**会话超过 24 小时会跳回登录页**。

2. **普通用户看不到「用户管理」**
   用户管理页签对非管理员隐藏；用户增删改必须管理员；新建用户密码至少 8 位；
   不能再通过改参数把自己提权成管理员（角色每次实时查库，账号被禁用立即失效）。

3. **使用初始密码的账号必须先改密码**
   带"必须改密码"标记的账号只能调用登录/改密相关接口，其余功能一律拒绝，
   提示「请先修改初始密码后再使用其他功能」。改密页本身不受影响，不会卡死。
   > 实测：现有 admin 账号的 `must_change_password = 0`，**不会被锁死**。

4. **文件读写路径受限**
   导入/导出等文件操作只放行两类路径：应用数据目录内，或你在对话框里自己选的目录。
   磁盘根目录、`C:\Windows`、`Program Files`、`System32` 等一律拒绝。
   写文件时额外拦截 `.exe/.bat/.cmd/.ps1` 等可执行/脚本后缀。

   **读取统一为公司同一套口径**（2026-09-19 收口）：凡是"把文件内容读进来"的通道——
   AI 聊天/AI 分析的附件、截图与证据预览、标准 JSON 导入、知识库上传——都只接受
   **数据目录内的文件**或**你自己亲手在对话框挑过的文件**。
   正常操作不受影响（所有这类文件都是你点"选择文件"挑的）；
   登记表会记下这些**路径**（不含内容，约几 KB），存在数据目录里，
   所以"上次选过的附件重开软件还能读"，也不会像拷贝那样把数据目录撑大。

5. **不能通过本应用打开可执行文件**
   「打开文件/打开所在目录」遇到 `.exe/.bat/.cmd/.com/.scr/.msi/.ps1` 等会明确拒绝，
   提示「出于安全原因，不允许通过本应用打开 xxx 类型的文件」。

6. **远程连接默认走加密**
   - WinRM：默认 **HTTPS + 5986**（原为 HTTP 5985）；HTTP 下用 NTLM/Basic 会告警（Basic+HTTP 直接拒绝）
   - Oracle：默认 **TCPS**
   - MySQL / PostgreSQL / SQL Server：默认开启 TLS；Oracle / Redis 明文连接会告警

7. **AI 自定义接口地址不能指向内网**
   `127.0.0.1`、`10.x`、`172.16.x`、`192.168.x`、`169.254.x`、IPv6 本地地址等会被拦截（防 SSRF）。

8. **SSH 会校验主机指纹**
   首次连接新主机时记录指纹并提示（TOFU）；策略设为 `strict` 时未知主机直接拒绝连接。

9. **删除项目会连带清理未绑定资产的连接配置**
   这些配置里存着加密后的口令，过去会变成"孤儿凭据"留在库里，现在一并清除。
   **注意：已绑定到具体资产的配置不受影响。**

10. **日志不再落明文敏感信息**，落盘前统一脱敏。

## 三、数据、备份与迁移

1. **备份可以给口令加密**（AES-256-GCM）。不设口令仍然是明文备份——要加密就在备份时填口令。
2. **备份一致性提升**：优先用 SQLite 在线备份 API，不再因 WAL 未归档导致备份缺数据。
3. **跨版本恢复会被拒绝**：备份文件里记录了格式版本，不在兼容白名单内会明确报错而不是静默恢复成坏数据。
4. **数据库结构漂移自检**：每次启动比对代码定义与实际表结构，缺表缺列会告警；
   本轮已把历史遗漏的 7 张表、15 个列补进正式迁移。
5. **内置标准入驻改为单事务**：要么完整入驻，要么整体回滚，不会再出现"半个标准"的僵尸数据。
6. **命令库 319 条批量插入**改为单事务分批，初始化更快。
7. **AI 分析结果被截断时会提示**，不再静默返回半截 JSON。

### 8. 项目导入 / 导出 = 完整数据归档（新增）

项目列表页的「导入」「导出」不再是一张项目字段表，而是**整包带走 / 整包还原**：

- **导出的内容**：项目信息、项目成员、资产、连接配置、测评记录、问题清单、采集任务与结果、采集文档，
  以及这些记录引用到的**截图与证据文件**，还有项目所依赖的**测评标准与测评项**。
- **导出方式**：工具栏「导出」可多选项目打成一个包；表格操作列的「↓」按钮可单项目直接打包。
- **导入方式**：选归档包 → 先看清楚里面有什么（项目/资产/记录/问题/附件数量、是否有警告）→ 再决定怎么处理 → 开始导入。
- **冲突处理**：如果本机已经有同一个项目，可选
  **另存为副本**（推荐，原名后加「（导入副本）」）/ **覆盖**（先删后建，不可撤销）/ **跳过**。
- **可选加密**：导出时可设口令（至少 8 位），包会整体加密；导入时输错口令只会提示"密码错误"，不会解出坏数据。
- **还想要表格？** 导出对话框里可以选「表格清单（.xlsx）」，那是给人看的台账，字段比原来更全（客户、测评师、起止日期、说明、资产数、符合率），但**不能导回系统**。

几点说明：
- **设备连接口令默认不带走**。口令由系统安全存储加密，与机器和用户绑定，换机后即使带上也解不开；
  外发归档时不带更安全。确需同机恢复口令，导出时勾选「包含设备连接口令」。
- **标准随包走的用意**：测评记录依赖标准里的测评项，不带标准的话，还原后测评页会变成一堆没有题干的空记录。
- 归档包格式带版本号，版本不兼容会明确拒绝导入，不会静默导入成残缺数据。

## 四、⚠️ 需要你特别注意的 5 件事

### 1. 自动更新目前会失败（最高优先级）
安装包**尚未做代码签名**，而程序对下载到的安装包做强制签名校验，未签名一律拒绝执行。
→ 在配上代码签名证书之前，**终端的"自动更新"会失败**。
- 正确做法：配置签名证书后重新打包；
- 临时绕过：设置环境变量 `JSECPROBE_SKIP_SIGNATURE_CHECK=1`；
- 或把策略改成"未签名时告警但放行"。

### 2. 检查存量远程连接配置
WinRM / Oracle / Redis / MySQL / PG / SQL Server 的加密默认值都翻了。
如果现场服务器未提供 TLS/HTTPS，需要**在配置里显式关闭加密**，否则会连不上或告警。
→ 升级后建议逐个点一遍"测试连接"。

### 3. 备份口令丢了无法恢复
加密备份用口令派生的密钥，没有后门。**口令请单独留存**。

### 4. 打包版的数据目录位置
正式安装版的数据根目录是 **「文档」目录下的 `JSecProbeData`**（本机解析为 `D:\0-系统主文档\JSecProbeData`）。
首次启动时若发现 `C:\JSecProbeData` 会自动迁移，**且旧目录保留不删除**——
确认新目录数据完整后，再自行删除旧目录。

### 5. 泄露的令牌需要轮换
仓库里的明文令牌已替换为占位符，但**已经在 GitHub / R2 / GitCode 上生效的旧令牌，必须到各自后台手动轮换**，
改本地文件不会让已泄露的凭据失效。
