# JSecProbe v2.4.5 更新内容

本次以**编辑体验修复**和**上手引导重做**为主，另含一批界面打磨。建议所有用户升级。

## 修复

- **项目列表：自动保存不再打断输入**
  原先点「编辑」即启动保存倒计时，且保存后整表重载，导致填到一半就被踢出编辑态。现拆分「编辑态」与「脏标记」为两个独立状态：倒计时从最后一次输入起算（8 秒），退出编辑时才收尾；保存后就地回写服务端字段，**不再重建表格**，编辑状态与后续输入都保留。
- **系统构成（资产台账）：保存不再重排整表**
  原先每次保存都 `loadAssets()` 重载全部行，输入焦点与滚动位置丢失。现保存后只刷新分类统计与计数；新增行用创建接口返回体就地转为真实行。
- **保存往返瞬间的新输入不再被覆盖**
  名称、用途、备注等用户正在输入的字段一律以浏览器中的值为准，只回写 `id` / `updatedAt` / `progress` 等服务端计算字段。
- **保存失败的提示更准确**
  自动保存只清除成功落库的行，失败行保留脏标记由周期保存重试；手动保存区分「没有需要保存的修改」与「部分修改保存失败」，不再一律显示成功。

## 体验

- **新手引导按真实工作流重排**
  由原先绕着菜单介绍模块，改为 **建项目 → 录资产 → 现场核查 → 问题汇总 → 出报告** 的主线；支持键盘操作（← → 翻页、Enter 下一步、Esc 跳过）与焦点管理；播放进度可断点续播（超过 7 天或步骤变更则重新播放）；完结页提供可直接下手的行动按钮；高亮目标改用 `data-guide` 锚点，不再依赖易重复的 CSS 类名。
  全新环境尚无项目时，自动合并为「流程总览」并落到侧边栏，不会把用户推进空白页面。
- **三张核心页新增场景化首访提示**
  首次进入系统构成 / 现场核查 / 问题汇总时，给出该页操作要点的轻提示条，可关闭，各自独立记住；用户菜单中可随时「重置页面提示」。

## 界面

- 自动采集页命令列表改为卡片式布局，命令代码改为随内容收缩的内联代码片（等宽字体），点击卡片任意处即可勾选，选中卡片描边高亮。
- AI 智能辅助页 5 步进度条改为标准 stepper：圆点编号 + 连接线，完成步骤显示对勾、连接线转为蓝色；移除了原先无点击处理却显示手型的伪交互。
- 全局打磨：页面标题栏卡片化、统计卡样式统一、补全 CSS 设计变量（含 AI 主题色）、表格数字改为等宽对齐、多处深色主题配色修正。

## 兼容性

数据库结构无变更，v2.4.4 可直接覆盖升级；首次启动仍会自动备份数据文件。
