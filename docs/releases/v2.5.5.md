# JSecProbe v2.5.5 更新内容

本次是**功能与体验更新**：新增系统拓扑图分区分域功能，批量分析改为全量跨页 + 真分批，拓扑描述支持详尽生成与报告插图，并配套一批界面与稳定性优化。不改测评结论口径，升级后原有数据可直接沿用。

## 新增：系统拓扑图与分区分域

- 系统构成页新增**系统拓扑图页签**（置于分类导航首位），支持多张上传、缩略图预览、大图预览、下载、删除，最多 20 张；上传即按真实文件头校正扩展名并落盘。
- **AI 按分区分域识别**：可生成总述 + 各安全域的详尽描述（含具体设备名称/型号/数量、域间边界与访问方向、分条子项），并自动识别带虚线框外的成组终端/接入设备。
- 描述以**整段文本框直接编辑**，自动落库、往返无损；新增横向**阶段进度步骤条**（准备 → 读取图 → 提交 AI → 整理描述 → 完成），过程清晰可见。
- Word 合册、单系统、HTML 合册、单系统 PDF **四处报告均插入拓扑章节与图片**，风格统一。
- 删除项目/分组时同步清理拓扑图物理文件，避免孤儿文件。

## 批量分析：全量跨页 + 真分批

- 风险分析、整改建议、重大风险判定、问题描述等批量分析改为**加载当前筛选下的全部问题（跨页），按每批 5 条一次提交 AI**，不再是逐条调用或只处理当前页。
- 修复批量失败误报「分析完成」、取消时进度闪跳、进度订阅泄漏、连续点击竞争同一取消控制器等问题。
- 进度展示统一为批次/条目双维度，弹窗状态与后端真正对齐。

## 界面与体验

- 分类导航栏压缩间距与字号，13 个页签在最大化窗口下可完整显示；窄屏保留细滚动条兜底。
- 系统拓扑 AI 识别进度条改为**阶段步骤条 + 状态色**（完成绿 / 出错红），比单一进度条更直观。
- 风险/整改/重大风险批量弹窗的批次进度与逐项状态展示更清晰。

## 稳定性与数据正确性

- AI JSON 容错：救回逻辑遇到非法对象时跳过继续、不再整段放弃；解析上限放宽以容纳详尽描述。
- 图片 MIME 识别补齐 TIFF 小端/大端文件头，避免视觉模型收到错误 MIME。
- 附件上传/删除的类型声明与实际返回对齐；拓扑上传落库失败时回滚内存与物理文件，不再误报成功。
- 全面审查并修复拓扑与批量分析链路的进度错乱、孤儿文件、保存返回值忽略等隐患。
