# JSecProbe v2.5.2 更新内容

本次是一个**小版本功能更新**：新增「内置 + 自定义外链」模块，把现场测评常用的标准法规、漏洞库、配套在线工具与客户内网系统收进同一个入口；同时把原先散落在各视图里的硬编码外链统一收口。不改测评结论口径、不改已有业务数据。

## 新增：内置 + 自定义外链

- **两个入口**：顶栏图标，或任意页面按 `Ctrl+L` 唤起快捷面板（搜索、上下键选择、Enter 打开、Ctrl+Enter 复制、Esc 关闭）；「系统设置 → 外链管理」做增删改与批量维护。
- **卡片式界面**：快捷面板与管理页都改成导航站风格的响应式卡片网格，字段为「图标 / 来源与网络标签 → 名称 → 域名:端口 → 描述 → 访问」，整卡可点击打开；管理页保留拖拽排序、收藏置顶、隐藏、失效标记、复制与编辑。
- **内置 16 条**，分四组：标准法规（全国标准信息公共服务平台、TC260、网络安全等级保护网、网信办）、漏洞与预警（CNVD / CNNVD / CNCERT）、项目支持（白皮书、源码仓库、版本下载、问题反馈、官方导航站、Ollama 下载）、测评工具箱（等保高风险指引库 `JSecRisk`、等保测评命令台 `JSecCmd`、等保拓扑绘图平台 `JSecTopo`）。
- **自定义链接**：新增/编辑/删除、分组、图标文字、「需外网 / 内网」标记；导入 `sites.txt`、浏览器书签 HTML、本工具导出的 JSON，导出自定义链接 JSON 供团队共享。网址可嵌入 `{projectName}` / `{assetIp}` / `{standardCode}`，打开时自动带入当前上下文。
- **官方导航站就是一条内置外链**：点开即为最新内容，不做后台同步、不缓存外部清单；确实需要把站内链接搬进应用时，用「导入 sites.txt」手动完成。

## 架构与安全

- 内置清单是随版本打包的只读 seed；用户新增项与「对内置项的改名 / 排序 / 隐藏」单独存 `external_links` 表。升级内置清单不会冲掉用户的改动，内置项「删除」只降级为隐藏。
- 新增 URL 校验唯一入口 `electron/utils/external-url.ts`：协议规范化、拒绝非 http(s) scheme、`user:pass@` 钓鱼写法与空白/反斜杠歧义地址；**刻意不拦内网 IP** —— 现场测评常需打开客户内网的漏扫平台、堡垒机与 OA，这与 AI 请求地址的 SSRF 黑名单职责分开。
- 所有外链统一走 `externalLink:open` → `shell.openExternal`；系统 IPC、新窗口拦截、页面导航拦截共用同一套校验，日志只记录主机与来源，不记录带凭据的完整 URL。
- 白皮书按钮、两处 GitHub 链接、Ollama 下载页等原先硬编码的外链全部收编到内置 seed，URL 单一来源。
