# JSecProbe v2.5.6 更新内容

本次是**缺陷修复版本**：修复知识库「导入指导书」功能失效、自动采集的三项可靠性/安全问题、两条核查命令语法问题，以及更新检查中 R2 兜底源读到旧版本的问题。不改测评结论口径，升级后原有数据可直接沿用。

## 修复：知识库「导入指导书」无法使用

- **根因**：目录校验误用「仅允许应用数据目录」的规则，用户选桌面 / D 盘等目录时被静默拒绝；加上错误被包装层吞掉、前端只捕获异常不判断失败结果，界面表现为「选了目录却始终看不到文件、导入按钮一直禁用」，且没有任何提示。
- 目录改为允许桌面、移动盘等非系统保护目录，并把选中的文件登记为可读授权（与测评点导入同一套授权链路）。
- 失败时明确提示原因；批量导入逐文件反馈失败详情。
- 导入后的文档改为**复制到应用受管目录**并保存相对路径，避免原始文件被移动/删除后文档变成孤儿。

## 修复：自动采集可靠性与安全性

- **SSH 命令超时不再拖垮整个任务**：超时只关闭当前命令通道，不再销毁整条 SSH 连接；此前第一条命令超时会导致后续所有命令全部失败。
- **新增破坏性命令护栏**：SSH / WinRM 采集通道拦截 `rm -rf`、`dd`、`mkfs`、`shutdown`、`reg delete`、`useradd` 等高危命令（SQL / Redis 通道原本已有只读白名单）。新增 3 组测试验证：20 条危险命令被拦、24 条常见只读核查命令零误伤、现有 319 条命令库零误伤。
- **超时类型不再丢失**：WinRM / MySQL / Oracle / Redis 连接器原本把超时错误吞成普通失败，前端误显示为「错误」；现在正确标记为「超时」，便于现场排障。

## 修复：核查命令库两条命令

- 华为交换机端口安全：`display port-security interface`（缺少接口参数）改为 `display current-configuration | include port-security`。
- Tomcat 版本查看：`/usr/local/tomcat/bin/version.sh`（脚本缺解释器）改为 `sh /usr/local/tomcat/bin/version.sh`。
- 数据库与内置种子同步更新，新安装与升级后一致。

## 修复：更新检查的 R2 兜底源可能读到旧版本

- Cloudflare 自定义域名会缓存 `latest.yml`，即使 R2 源对象已是新版本，客户端仍可能读到旧版本而误判「已是最新」。现请求追加时间戳参数穿透缓存。
