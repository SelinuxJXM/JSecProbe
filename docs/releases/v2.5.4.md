# JSecProbe v2.5.4 更新内容

本次是**小版本质量与体验更新**：聚焦 AI 资产识别与现场核查的可靠性、数据落库正确性、以及批量操作体验。不改测评结论口径、不改已有测评数据，升级后原有数据可直接沿用。

## 系统构成：AI 资产识别更稳、更全、更清晰

- **按附件分批识别**：图片每批 5 张、文档每批 2 份，各批独立调用 AI 并合并去重，从根源避免输出过长被截断导致的 JSON 解析失败。
- **逐批阶段进度**：识别弹窗显示「批次 X/Y」与逐批清单（已完成 / 进行中 / 待处理），每条标注本批处理的图片 / 文档范围，过程可见。
- **识别上限提升至 300**：此前 10 份 Excel 只能识别出 50 个资产（后端硬截断），现按分批规模放宽到 300，并在超限时明确提示分两批识别。
- **字段语义对齐表格列**：修正文档类资产（sys_doc）「主要内容」错跑到「备注」列的问题；密码产品 / 安全人员 / 管理平台等类别的字段按表格列名语义填写；预览详情的字段名改为随资产类别动态显示，与导入后的表格列名一致。
- 新增多选与**批量删除**，勾选后一次确认即可删除多个资产。

## 现场核查：AI 批量分析更可靠

- **结论正文纯化**：不再把逐点核查罗列、编号列表、「判定为不符合」等判定套话写进测评结论；判定只由独立的符合性字段承载。
- **批量 JSON 容错**：支持 AI 返回代码围栏包裹的内容，解析失败时逐对象救回，不再整批丢失；分批提交并将批大小降到 5，降低相邻相似测评项结论错配概率。
- **条款错配自动纠正**：用 AI 回显的条款原文校验 itemId 与结论的对应，发现相邻相似项写反时自动纠正并提示。
- **关联证据文件落盘**：按 AI 判定把相关截图 / 文档真正关联为可点击预览的附件，并校验附件与测评项的匹配，错配的直接丢弃。

## 新增：测评点知识库

- 从等保测评指导书 Excel 导入测评点（语义键构建、模糊匹配、纯编号过滤），AI 分析时按测评项召回并注入提示词，辅助逐项核查不遗漏。

## 稳定性与数据正确性

- 删除单元格、批量粘贴、批量改符合性等离散操作统一标脏并触发自动保存，修复「删除后不保存、手动保存又提示无更改」的问题。
- API 限流（429）改为退避重试一次且不再误判为模型故障降权 5 分钟，连续跑多个批量 AI 分析不再频繁失败。
- 修复切换测评对象 / 全局域时的保存竞态、导入后表格不刷新、批量弹窗提前关闭导致按钮与数据时序脱节等问题。
- 报告与文档提取多处健壮性修正。
