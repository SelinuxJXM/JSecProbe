# JSecProbe v2.5.3 更新内容

本次是**小版本功能更新**：在完成前四个阶段（系统构成 → 现场核查 → 风险分析 → 整改建议）之后，新增**第五阶段「重大风险隐患识别与分析」**；同时把风险分析从矩阵式改为问题清单式，并新增按《等保测评高风险判定指引》自动定级。项目升级为**多系统管理**，项目列表状态改为按名下系统自动同步。不改测评结论口径、不改已有测评数据。

## 新增：第五阶段「重大风险隐患识别与分析」

- **内置你提供的 32 条重大风险隐患清单**（6 列：序号 / 安全域 / 控制点 / 测评项 / 触发项 / 安全问题描述，5 个安全域），首次启动自动入驻「清单管理」；可直接导入、逐条编辑与启停，导入为全量替换，升级种子版本不会覆盖你改过的条目。
- **AI 三要素分析**：从风险分析的「问题描述」识别问题，按关键词与场景召回清单条目，并**检索全系统的现场测评记录**（含防火墙策略、WAF、专网隔离、账号专人专用等防护措施与环境信息），按**相关性 / 严重性 / 高发性各写一段**并给出「属于 / 不属于 / 待判定」结论。判定原则按你清单顶部原文校准：三要素须同时满足；相关性要求未采取任一缓解措施，高发性要求综合已部署防护与是否发现实际被利用痕迹。
- **人工复核**：单条识别回填编辑框、批量识别先存草稿，均可修改结论与三要素文字并记录复核人 / 时间；支持 Excel 导出与报告新增章节「4.4 重大风险隐患识别与分析」（Word / PDF / HTML / 合册报告）。
- **批量进度弹窗**：与整改建议批量 AI 同一套 UI——逐条进度、耗时与预计剩余、最小化、中止识别、成功 / 失败统计；深浅主题均适配。

## 新增：多系统项目与状态自动同步

- 项目（分组）1:N 被测系统，业务数据仍按系统隔离，报告 / 归档 / 统计 / AI 零冲突；入口 `/projects/:groupId/systems`，分组 CRUD 与项目列表过滤同步支持。
- **项目状态不再手工维护**：任一系统进行中 → 项目进行中；系统全为草稿 → 草稿；全为已完成 → 已完成；草稿与已完成混合且无进行中 → 进行中（还有系统未完成）。归档系统不参与计算；手动归档的项目保持归档态，取消归档自动回推真实状态。
- 状态在列表读取时按系统实时推导（存量数据立即生效）、系统状态变更 / 增删 / 导入归档时写路径同步并留操作日志。

## 调整：风险分析页与自动定级

- 风险分析改为**问题清单式三要素分析**（问题分析列「可能导致 XXXX 的风险」），不再使用矩阵 / 风险值 / 结论等级 / 处置策略；沿用原有 11 个 `risk_*` 列中的 3 列，不新增迁移。
- 新增「按高风险判定指引自动定级」：单条 / 批量依据内置的等保高风险判定指引库召回候选条目，AI 判定风险等级并回填，带 5 步流程指示、逐条进度弹窗、中止与人工复核；报告与 Excel 导出同步风险分析口径。

## 体验与质量保障
