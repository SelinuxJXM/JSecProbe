## 一、产品概述

### 1.1 产品背景

网络安全等级保护制度（等保 2.0）是国家网络安全的基础性工作。根据《网络安全法》和《信息安全技术 网络安全等级保护基本要求》（GB/T 22239-2019），二级及以上信息系统必须定期进行等级测评。然而，传统的现场测评工作长期面临以下痛点：

- **流程繁琐**：项目立项、资产梳理、现场核查、问题整改、报告撰写等环节依赖手工操作，效率低下
- **标准复杂**：GB/T 22239-2019 包含 10 大安全域、300+ 测评项，人工对照极易遗漏
- **协作困难**：测评团队成员之间数据不同步，核查记录难以共享复用
- **报告耗时**：测评报告编写占用大量时间，格式不统一、内容不完整
- **知识壁垒**：新入职测评人员缺乏经验，核查方法和整改建议依赖个人积累

### 1.2 产品定位

JSecProbe 是一款面向等保测评机构和被测单位信息管理人员的一站式桌面端测评工具，致力于将等保现场测评工作**数字化、标准化、智能化**。

### 1.3 核心价值

| 价值维度 | 具体体现 |
|----------|----------|
| **效率提升** | 自动化核查、批量导入导出、自动生成报告，大幅减少重复劳动 |
| **标准合规** | 严格对标 GB/T 22239-2019，内置三级/二级标准库 |
| **质量保障** | 统一的测评流程和数据记录，减少人为遗漏 |
| **知识沉淀** | 内置知识库和核查命令库，帮助新人快速上手 |
| **智能辅助** | AI 辅助分析核查记录、自动生成问题描述和整改建议 |

### 1.4 技术架构

| 层级 | 技术选型 | 说明 |
|------|----------|------|

## 二、产品特色

### 2.1 全流程覆盖

JSecProbe 覆盖等保现场测评的**完整工作链路**：

```
项目立项 → 资产录入 → 现场核查 → 问题管理 → 报告生成 → 整改跟踪
```

每个环节都有对应的数字化工具支撑，实现"一个工具完成全部工作"。

### 2.2 标准深度内置

- **三级测评项**：300+ 条测评项完整覆盖 GB/T 22239-2019 第三级要求的全部 10 个安全域
- **二级测评项**：200+ 条测评项覆盖第二级要求
- **扩展要求**：支持云计算、移动互联、物联网、工业控制、大数据、关键信息基础设施六大扩展类型
- **自动筛选**：根据项目等级自动筛选适用的测评项，避免人工判断遗漏

### 2.3 AI 智能辅助

| AI 功能 | 说明 |
|---------|------|
| **智能测评** | 输入命令执行结果或上传截图，AI 自动判断符合性并生成测评记录 |
| **问题描述** | AI 自动将冗长的问题分析提炼为一句话概括 |
| **整改建议** | AI 根据问题自动生成针对性的整改建议（单条或批量） |
| **批量分析** | 支持多截图并发处理，智能匹配测评项，实时显示进度 |
| **隐私保护** | 自动脱敏 IP/MAC/域名/密码等敏感信息后再发送给 AI |
| **本地大模型** | 支持 Ollama 部署本地模型，数据不出内网 |

### 2.4 知识库体系

内置三大知识模块：

- **等保标准库**：GB/T 22239-2019 标准全文结构化存储，支持分类检索
- **作业指导书**：各类设备的测评操作指南，按安全域组织
- **核查命令库**：预置 100+ 条核查命令，涵盖华为/H3C/Cisco 交换机、深信服/天融信防火墙、Linux/Windows 服务器、MySQL/Oracle/SQL Server/PostgreSQL/Redis 数据库、Nginx/Apache/Tomcat/WebLogic/IIS 中间件、Docker/Kubernetes 容器等

### 2.5 数据安全设计

| 安全措施 | 实现方式 |
|----------|----------|
| 密码存储 | bcrypt 12 轮哈希加密 |
| 登录防护 | 连续 5 次失败锁定 5 分钟，防暴力破解 |
| 会话管理 | 24 小时超时自动失效 |
| 路径安全 | 所有文件操作验证路径，防止路径遍历攻击 |
| SQL 注入防护 | 全量使用 Drizzle ORM 参数化查询 |
| XSS 防护 | 输入内容净化处理 |
| SSRF 防护 | API 地址云元数据端点黑名单 |
| 图片校验 | Magic Number 验证文件真实类型 |
| AI 隐私 | 文本脱敏后再发送，支持自定义敏感词 |

### 2.6 离线优先

- 基于 SQLite 的嵌入式数据库，无需连接服务器
- 支持 Ollama 本地大模型，内网环境下仍可正常使用 AI 功能
- 所有数据存储在本地 `JSecProbeData` 目录，完全掌控数据主权

### 2.7 自动更新

采用**双源更新策略**，确保更新可靠性：

1. **主源**：GitHub Releases（electron-updater）
2. **备源**：Cloudflare R2 对象存储

支持版本检测、下载进度显示、SHA512 校验、静默安装。

## 三、功能详解

### 3.1 用户认证与权限管理

**功能入口**：登录页 / 个人中心 / 系统设置

#### 3.1.1 用户登录

- 用户名 + 密码登录方式
- bcrypt 12 轮密码哈希存储
- 连续 5 次登录失败自动锁定 5 分钟（防暴力破解）
- Session-based 认证，24 小时超时自动登出

#### 3.1.2 角色管理

| 角色 | 权限 |
|------|------|
| 管理员（admin） | 全部功能权限，包括用户管理 |
| 测评员（assessor） | 项目管理、现场核查、报告生成 |

#### 3.1.3 密码管理

- 用户自主修改密码（需验证旧密码，最少 8 位）
- 管理员可重置其他用户密码

### 3.2 工作台（Dashboard）

**功能入口**：登录后首页

工作台提供项目全局概览，包括：

- **项目统计**：总数、进行中、已完成、草稿、归档各状态数量
- **等级分布**：二级/三级/四级项目占比
- **资产概览**：全部项目的资产总数
- **快速入口**：一键跳转至项目管理、现场核查、AI 助手等模块

### 3.3 项目管理

**功能入口**：左侧导航 → 项目管理

#### 3.3.1 项目创建

- 自动生成项目编号（DJCP-XXX 格式）
- 设置项目名称、所属单位、保护等级
- 等级组合设置（SxAxG），自动计算最终保护等级
- 支持扩展类型：云计算、移动互联、物联网、工业控制、大数据、关键信息基础设施

#### 3.3.2 项目状态流转

```
草稿 → 进行中 → 已完成 → 已归档
```

每个状态变更自动记录操作日志。

#### 3.3.3 项目导入/导出

| 操作 | 格式 | 说明 |
|------|------|------|
| 导出单项目 | Excel | 含项目基本信息 + 资产列表 |
| 导出全部项目 | Excel | 所有项目的汇总清单 |
| 导入项目 | Excel | 从模板批量导入项目 |

#### 3.3.4 项目进度

- 自动计算测评完成进度（基于测评记录填写率）
- 按资产×测评项计算总项数
- 可视化展示各安全域完成情况

### 3.4 系统构成（资产管理）

**功能入口**：项目管理 → 某项目 → 系统构成

#### 3.4.1 资产类别

系统支持 10 类资产的管理：

| 序号 | 资产类别 | 关键属性 |
|------|----------|----------|
| 1 | 管理机房 | 机房名称、位置、面积、温湿度 |
| 2 | 区域边界 | 边界名称、连接区域、防护措施 |
| 3 | 网络设备 | 设备名称、品牌型号、IP、OS版本、固件版本 |
| 4 | 安全设备 | 设备名称、品牌型号、IP、防护类型 |
| 5 | 服务器/存储设备 | 设备名称、IP、操作系统、数据库、中间件 |
| 6 | 系统管理平台 | 平台名称、版本、管理范围 |
| 7 | 业务应用系统 | 系统名称、版本、开发商、用户数 |
| 8 | 业务终端/运维终端 | 终端类型、操作系统、数量 |
| 9 | 数据资源 | 数据类型、数据量、重要程度 |
| 10 | 系统管理文档 | 文档名称、类型、版本、更新日期 |

#### 3.4.2 资产操作

- **增删改查**：完整的 CRUD 操作
- **批量删除**：支持选中多条资产一次性删除
- **模板下载**：下载带示例数据的 Excel 模板
- **导入导出**：
  - 导入：支持多 Sheet 自动识别，按 Sheet 名称匹配资产类别
  - 导出：支持单类别导出或全部导出
- **预置测评记录**：导入资产时可自动创建对应的测评记录

### 3.5 现场核查（测评核心）

**功能入口**：项目管理 → 某项目 → 现场核查

这是 JSecProbe 的核心功能模块，用于执行实际的等保测评工作。

#### 3.5.1 测评项导航

- **按安全域分层**：10 个安全域逐层展开
- **等级筛选**：筛选"二级起适用"或"仅三级适用"的测评项
- **扩展类型筛选**：通用要求 / 云计算 / 移动互联 / 物联网 / 工业控制 / 大数据 / 关基
- **搜索功能**：按测评项名称或编号快速定位

#### 3.5.2 测评记录填写

每个测评项可记录：

| 字段 | 说明 |
|------|------|
| 符合性判定 | 符合 / 部分符合 / 不符合 / 不适用 / 待判定 |
| 核查方法 | 核查 / 访谈 / 审查 / 测试 |
| 命令输出 | 执行核查命令的结果文本 |
| 核查说明 | 文字描述的核查过程和结论 |
| 证据截图 | 上传的图片证据 |
| 证据文件 | 上传的文档证据（PDF/Word/Excel 等） |

#### 3.5.3 截图管理

- **上传截图**：文件选择方式上传
- **粘贴截图**：从剪贴板直接粘贴（自动保存为 PNG）
- **截图预览**：Base64 编码在线预览
- **OCR 识别**：截图自动文字提取（支持中英文）
- **AI 分析**：截图批量发送给 AI 进行智能分析

#### 3.5.4 核查命令库

- 内置 100+ 条核查命令
- 按设备类型和安全维度分类
- 支持命令收藏、搜索、导入/导出
- 涵盖主流厂商：华为、H3C、Cisco、深信服、天融信等

#### 3.5.5 自动保存

- 测评记录自动保存（composable 实现）
- 防止意外关闭导致数据丢失
- 保存状态实时提示

#### 3.5.6 进度统计

- 按资产×测评项计算总测评项数
- 实时统计已完成/未完成数量
- 按安全域展示完成进度

#### 3.5.7 测评记录导入/导出

- **导出 Excel**：包含嵌入图片和超链接，支持按层面/资产筛选
- **导入 Excel**：支持选择层面和资产进行批量导入

### 3.6 问题清单管理

**功能入口**：项目管理 → 某项目 → 问题清单

#### 3.6.1 问题自动生成

- 系统自动扫描"不符合"和"部分符合"的测评记录
- 一键生成问题清单，自动关联测评项和安全域

#### 3.6.2 问题属性

| 字段 | 说明 |
|------|------|
| 问题名称 | 一句话概括的问题描述 |
| 关联测评项 | 自动关联对应的测评标准条款 |
| 风险等级 | 高风险 / 中风险 / 低风险 |
| 问题状态 | 待整改 / 整改中 / 已整改 / 已关闭 |
| 整改建议 | 详细的整改措施建议 |
| 整改期限 | 计划完成整改的日期 |
| 责任人 | 负责整改的人员 |
| 证据文件 | 整改前后的证据材料 |

#### 3.6.3 问题排序

- 按安全域分组展示
- 安全计算域内按资产类型排序
- 高风险问题优先置顶

#### 3.6.4 问题导入/导出

- **导出 Excel**：按安全域分 Sheet 导出
- **导入 Excel**：按模板格式批量导入问题
- **统计摘要**：按风险等级/状态/安全域生成统计图表

## 四、快速上手

### 4.1 环境要求

| 项目 | 要求 |
|------|------|
| 操作系统 | Windows 10/11（64 位） |
| 内存 | 建议 4GB 及以上 |
| 磁盘空间 | 建议 2GB 及以上可用空间 |
| AI 功能 | 联网（云端模式）或安装 Ollama（本地模式） |

### 4.2 安装步骤

1. 从 [GitHub Releases](https://github.com/SelinuxJXM/JSecProbe/releases) 下载最新安装包
2. 运行 `JSecProbe_Setup_x.x.x.exe`
3. 选择安装目录（默认 `C:\Program Files\JSecProbe`）
4. 完成安装，启动应用

### 4.3 首次登录

- 默认管理员账号：`admin`
- 默认密码：`admin123`
- **安全提示**：首次登录后请立即修改默认密码

### 4.4 创建第一个项目

**步骤 1：新建项目**

1. 点击左侧导航「项目管理」
2. 点击「新建项目」
3. 填写项目信息：
   - 项目名称：XX 单位等保测评项目
   - 保护等级：三级
   - 扩展类型：通用要求（默认）
4. 点击「创建」

**步骤 2：录入资产**

1. 进入新建项目的「系统构成」
2. 点击「下载模板」获取 Excel 模板
3. 在模板中填写资产信息
4. 点击「导入资产」上传填写好的 Excel
5. 检查导入结果

**步骤 3：执行现场核查**

1. 进入项目的「现场核查」
2. 选择安全域（如「安全计算环境」）
3. 选择资产（如某台服务器）
4. 选择测评项，填写核查记录：
   - 执行核查命令
   - 将命令结果复制到「命令输出」
   - 上传截图证据
   - 判定符合性
5. 记录自动保存，继续下一条

**步骤 4：生成问题清单**

1. 进入项目的「问题清单」
2. 点击「自动生成问题」
3. 系统扫描不符合/部分符合的测评记录
4. 审核生成的问题，补充整改建议

**步骤 5：生成报告**

1. 点击「生成报告」
2. 选择报告模板（标准版）
3. 选择输出格式（DOCX 或 PDF）
4. 等待报告生成
5. 预览并保存

### 4.5 使用 AI 辅助

**步骤 1：配置 AI**

1. 进入「AI 智能辅助」
2. 点击「AI 配置」
3. 选择模式：
   - 云端模式：输入 API Key 和 Base URL
   - 本地模式：确保 Ollama 已安装运行
4. 点击「测试连接」验证配置

**步骤 2：AI 分析测评**

1. 在「现场核查」中，选择一条测评项
2. 点击「AI 分析」按钮
3. 上传截图或粘贴命令输出
4. 等待 AI 分析完成
5. 审核 AI 生成的测评记录

**步骤 3：批量分析**

1. 在「现场核查」中，点击「批量 AI 分析」
2. 选择多张截图
3. 点击「开始分析」
4. 实时查看进度
5. 审核并应用结果

## 五、常见问题解答（FAQ）

### 5.1 安装与启动

**Q：安装包下载后无法安装怎么办？**

A：请按以下步骤排查：
1. 确认下载完整（对比文件大小）
2. 右键安装包 → 属性 → 勾选"解除锁定"（如有）
3. 以管理员身份运行安装包
4. 临时关闭杀毒软件（部分安全软件可能误报）

**Q：启动时提示缺少 DLL 文件怎么办？**

A：安装 [Visual C++ Redistributable](https://aka.ms/vs/17/release/vc_redist.x64.exe) 后重试。

**Q：便携版和安装版有什么区别？**

A：

| 对比项 | 安装版 | 便携版 |
|--------|--------|--------|
| 安装方式 | 需要安装程序 | 解压即用 |
| 快捷方式 | 自动创建 | 手动创建 |
| 卸载方式 | 控制面板卸载 | 直接删除文件夹 |
| 数据存储 | 用户 AppData 目录 | 程序目录下的 JSecProbeData |

### 5.2 登录与账户

**Q：忘记管理员密码怎么办？**

A：如果还有其他管理员账号，可用其登录并重置密码。否则需要手动修改数据库：
1. 关闭应用
2. 打开 `JSecProbeData/database.sqlite`
3. 使用 SQLite 工具重置密码哈希

**Q：登录时提示"账户已锁定"？**

A：连续 5 次登录失败会触发 5 分钟锁定。等待 5 分钟后重试，或联系管理员解锁。

**Q：如何修改密码？**

A：登录后进入「个人中心」→「修改密码」，输入旧密码和新密码（至少 8 位）。

### 5.3 项目管理

**Q：项目编号可以自定义吗？**

A：系统自动生成 DJCP-XXX 格式编号。如需自定义编号，可在项目名称中包含标识。

**Q：删除的项目可以恢复吗？**

A：项目删除后无法直接恢复。建议：
1. 删除前先导出项目数据（Excel）
2. 定期使用「备份与恢复」功能备份全部数据
3. 如需恢复，可从备份 ZIP 中增量恢复该项目

**Q：项目状态如何流转？**

A：项目状态按 `草稿 → 进行中 → 已完成 → 已归档` 顺序流转。在项目详情页可手动变更状态。

### 5.4 资产与系统构成

**Q：资产导入时部分数据未导入成功？**

A：请检查：
1. Excel 模板格式是否与下载的模板一致
2. Sheet 名称是否与资产类别名称完全匹配
3. 必填字段是否填写完整
4. 导入失败的行会在结果提示中列出

**Q：如何批量修改资产信息？**

A：先导出资产到 Excel，在 Excel 中批量修改后重新导入（导入时会自动匹配更新）。

### 5.5 现场核查

**Q：测评记录会自动保存吗？**

A：是的。系统采用自动保存机制，填写过程中无需手动保存。保存状态会在界面显示。

**Q：如何批量填写相同的测评记录？**

A：可以使用「导入测评记录」功能：
1. 导出当前项目的测评记录（含空白记录）
2. 在 Excel 中批量填写
3. 重新导入

**Q：截图上传有什么限制？**

A：
- 支持的格式：PNG、JPG、JPEG、GIF、BMP、WebP
- 单张最大 20MB
- 大于 120KB 的图片会自动压缩

**Q：OCR 识别不准确怎么办？**

A：
1. 确保截图清晰、文字对比度足够
2. 尽量使用中文语言包（eng.traineddata 已内置）
3. 对于复杂版面，建议裁剪后单独识别
4. OCR 结果仅供参考，重要内容请人工核对

### 5.6 AI 功能

**Q：AI 功能无法使用怎么办？**

A：按以下步骤排查：
1. 检查 AI 配置是否正确（API Key、Base URL）
2. 测试网络连接是否正常
3. 检查 API 额度是否充足
4. 查看应用日志（`JSecProbeData/logs/`）获取详细错误信息

**Q：本地模式需要什么样的硬件配置？**

A：

| 配置项 | 最低要求 | 推荐配置 |
|--------|----------|----------|
| 内存 | 8GB | 16GB |
| 磁盘空间 | 10GB 可用 | 20GB 可用 |
| GPU | 无要求 | NVIDIA GPU（加速推理） |

**Q：AI 分析的准确率如何？**

A：AI 分析结果仅供参考。建议：
1. 重要测评项人工复核 AI 结果
2. AI 生成的测评记录需审核后保存
3. 对于不符合的判定，建议补充详细说明

**Q：使用 AI 功能会泄露数据吗？**

A：系统内置多层隐私保护：
1. 所有文本在发送前自动脱敏（IP/MAC/域名/密码等）
2. 支持本地大模型模式，数据完全不出内网
3. 支持自定义敏感词过滤
4. 日志中不记录完整的 AI 请求内容

### 5.7 报告生成

**Q：报告中的中文字体显示不正确怎么办？**

A：DOCX 报告使用仿宋/宋体作为中文字体。如显示不正确，请确保系统已安装相应字体。

**Q：可以自定义报告模板吗？**

A：当前版本提供三种预设模板（简洁版/标准版/详细版）。如需定制模板，可联系技术支持。

**Q：报告生成失败怎么办？**

A：
1. 检查项目数据是否完整（至少有一条测评记录）
2. 检查磁盘空间是否充足
3. 查看详细错误日志（`JSecProbeData/logs/`）

### 5.8 数据备份

**Q：数据存储在哪里？**

A：所有数据存储在 `JSecProbeData` 目录下，包含：
- `database.sqlite` — 数据库文件
- `screenshots/` — 截图目录
- `evidence/` — 证据文件目录
- `attachments/` — 附件目录
- `logs/` — 日志目录

**Q：卸载应用会删除数据吗？**

A：卸载**不会**自动删除 `JSecProbeData` 目录。但为安全起见，**卸载前请务必手动备份数据**。

**Q：如何迁移数据到另一台电脑？**

A：
1. 在旧电脑上使用「完整备份」功能
2. 将备份 ZIP 复制到新电脑
3. 在新电脑上使用「数据恢复」功能
4. 选择「完整 ZIP 恢复」

### 5.9 自动更新

**Q：如何检查更新？**

A：进入「系统设置」→「系统信息」，点击「检查更新」。

**Q：更新失败怎么办？**

A：
1. 检查网络连接是否正常
2. 手动从 [GitHub Releases](https://github.com/SelinuxJXM/JSecProbe/releases) 下载安装包
3. 覆盖安装（数据不会丢失）

**Q：更新会丢失数据吗？**

A：不会。更新只替换程序文件，不影响 `JSecProbeData` 目录中的数据。但建议更新前仍做一次完整备份。

### 5.10 性能与兼容性

**Q：项目数据量大了会卡吗？**

A：SQLite 在处理中小型数据集（<100MB）时性能良好。建议：
1. 单个项目的截图和证据文件控制在合理数量
2. 定期归档已完成的项目
3. 单个项目资产数量建议不超过 500 条

**Q：支持 Windows 7 吗？**

A：不支持。最低要求 Windows 10（64 位）。Electron 29+ 已停止对 Windows 7 的支持。

**Q：可以和其他杀毒软件共存吗？**

A：可以。如出现误报，请将 JSecProbe 添加到杀毒软件的白名单。
