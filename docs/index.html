关于 JSecProbe 的常见疑问解答

当前版本仅支持 Windows 10/11（64 位）。需要 4GB 以上内存、2GB 以上磁盘空间。AI 功能需要联网（云端模式）或安装 Ollama（本地模式）。

不是必须的。JSecProbe 支持两种 AI 模式：云端模式（DeepSeek/GPT 等 OpenAI 兼容 API）和本地模式（Ollama 部署本地大模型）。本地模式下，数据完全不出内网，适合对数据安全要求高的场景。

系统内置多层安全保护：所有数据存储在本地 SQLite 数据库；AI 发送前自动脱敏 IP/MAC/域名/密码等敏感信息；支持自定义敏感词过滤；支持本地大模型模式，数据完全不出内网。

在旧电脑上使用「完整备份」功能生成备份 ZIP，复制到新电脑后使用「数据恢复」功能即可。所有项目、资产、测评记录、截图都会完整迁移。

如果有其他管理员账号，可用其登录并重置密码。否则需要手动修改数据库：关闭应用 → 打开 JSecProbeData/database.sqlite → 使用 SQLite 工具重置密码哈希。
