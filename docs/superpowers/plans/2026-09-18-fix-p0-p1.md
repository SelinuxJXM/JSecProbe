# P0/P1 问题修复实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修复全面审查发现的 P0（数据库/迁移/数据完整性）与 P1（构建/依赖安全）问题，不改变产品功能。

**Architecture:**
- Phase A（P0）聚焦数据库层：修正迁移 SQL 建表顺序、清理未登记孤儿迁移、统一 createdAt 时间格式、补充应用级级联删除与索引、修复种子重灌与 VACUUM 路径注入。
- Phase B（P1）聚焦构建/依赖层：用 exceljs 替换存在 CVE 的 xlsx、`.env.example` 脱敏、latest.yml 补充 blockmap、上传脚本幂等、补充 typecheck 脚本。Electron 大版本升级与代码签名因涉及外部证书/网络下载，单独列为高风险验证项。

**Tech Stack:** Electron 29 + Vue 3 + TypeScript + better-sqlite3 + Drizzle ORM + exceljs + electron-builder
