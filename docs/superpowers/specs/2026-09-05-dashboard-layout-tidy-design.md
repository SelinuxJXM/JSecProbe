# 工作台布局重排设计（方案 A：16:8 统一分栏）

日期：2026-09-05
状态：已获用户批准

## 背景

用户反馈工作台页面两点问题：

1. 不需要展示「资产总数」统计卡
2. 卡片排版乱、不够整齐

代码审查确认的排版问题：

| # | 问题 | 证据 |
|---|------|------|
| 1 | 统计行 4 卡中「资产总数」需移除，直接删会留 1/4 空白（4×span6=24） | `stats-row` 第 4 张卡 |
| 2 | 行间距不统一：统计行与首内容行之间 24px，三个 `content-row` 之间 0 间距（卡片贴合） | scoped 样式 `.stats-row` 有 `margin-bottom`，`.content-row` 无 |
| 3 | 分栏错位：第 2/3 行 16:8，第 4 行 12:12，竖直分割线不对齐 | 模板 `el-col :span` |
| 4 | 同行卡片高度不一：卡片无等高处理，底边参差 | `.content-row .card` 无 `height: 100%` |

## 方案（用户已选定 A）

```
[项目总数 8] [进行中 8] [已完成 8]
[最近项目 16]                [状态分布 8]
[创建趋势 16]                [系统状态 8]
[等级分布 16]                [快捷操作 8]
```

备选方案 B（统一 12:12）因最近项目表格 5 列在半屏过挤被否决。

## 改动清单（仅 `src/views/dashboard/index.vue`）

### 模板
- 删除资产总数统计卡（含 `Monitor` 图标的 `el-col`）
- 3 张统计卡 `span 6 → 8`
- 第 4 行：等级分布 `span 12 → 16`，快捷操作 `span 12 → 8`

### script
- 从 icons 导入中删除 `Monitor`（仅资产总数卡使用）
- `stats.assetCount` 赋值保留（`getStatistics` 返回结构不动，仅界面不展示）

### 样式
- `.content-row` 增加 `margin-bottom: var(--spacing-lg)`，与统计行行距一致；末行用 `:last-child { margin-bottom: 0 }` 清零
- `.content-row .card` 增加 `height: 100%`（el-row 为 flex，卡片拉伸等高、底边对齐）

### 深色模式
全部使用现有 CSS 主题变量，无新增硬编码颜色。

## 非目标

- 不改动其他页面与组件
- 不改动后端统计接口与 `shared/types.ts`
- 不改动引导组件（OnboardingGuide）

## 验证

1. `npx vue-tsc --noEmit` 通过
2. dev 热更新后人工核对：统计行 3 卡等宽铺满、四行分割线对齐、同行卡片底边对齐、行距统一 24px、深浅色回归
